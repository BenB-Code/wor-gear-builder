La méthode

  • Fraîcheur — chaque cycle démarre par 3 analyses à froid, sans lecture des rapports précédents ;
  • Débat — les trois se lisent et se contestent (appuis, contestations, fusions, révisions, collines) — les documents bruts sont conservés dans les materials/ de chaque cycle ;
  • Challenge — un modérateur confronte le cycle au rapport précédent : confirme / contredit / apporte / a raté ;
  • Arbitrage — le rapport final tranche tout, y compris les cinq amendements du client (C1-C5).
